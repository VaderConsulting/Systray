# Systray

VB6 system-tray bag: a `SysTray Icon Control` OCX (`2/Systray.vbp`), the CypherSolutions `SysTrayExample` tray icon demo (`1/SysTrayExample.vbp`), and the DOJ Marquee Settings app (`TuskMarqueeSettings.vbp`) that sits in the tray using `flshtray.ocx`. Open any of the three `.vbp` files in the VB6 IDE.

**Source last updated:** 2001-08-23 · **Language:** VB6 · **Target:** VB6 Win32 · **Output:** ActiveX OCX, WinForms exe

## Solution structure

| Project | Language | Type | Purpose |
|---------|----------|------|---------|
| `SysTrayCtl` (`2/Systray.vbp`) | VB6 | ActiveX OCX | System Tray Icon Control (`SysTray.ocx`) |
| `SysTrayExample` (`1/SysTrayExample.vbp`) | VB6 | WinForms exe | System tray icon example |
| `DOJMarqueeSettings` (`TuskMarqueeSettings.vbp`) | VB6 | WinForms exe | DOJ Marquee Settings tray UI |

## How to open

Open the `.vbp` in Visual Basic 6.0 IDE:
- `2/Systray.vbp` (or `2/Group1.vbg`)
- `1/SysTrayExample.vbp`
- `TuskMarqueeSettings.vbp`

## Requirements

- Visual Basic 6.0 IDE
- flshtray.ocx for DOJ Marquee Settings
